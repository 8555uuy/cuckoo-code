# Cuckoo Code v0.8.19

## 🌟 亮点速览
- **内置插件市场**：全新安装自动预置 `dshmarket`，同时支持老用户平滑增量升级。
- **新增「日志」面板**：主界面设置中新增日志功能，一键开启排障、清空和直达日志目录。

---

## 🚀 新增与内置
- **内置 `dshmarket` 插件**：将插件市场作为默认内置插件，并为其补齐了运行所需的 `js-yaml` 和 `undici` 依赖。
- **智能增量补全**：优化了内置插件的注入逻辑。新版本增加的内置插件会平滑推送给老用户；同时严格尊重用户操作，若手动卸载则不会“死灰复燃”。
- **设置 - 日志管理**：新增日志开关、日志文件大小展示、一键清空日志以及快速打开日志目录功能（仅安装版生效，方便排查环境问题）。

## 🐛 核心修复
- **修复安装版 DSH 插件加载失败（`ENOENT`）**：由于 Electron 的 `app.asar` 机制不允许直接 `spawn` 虚拟包内的程序，导致 `esbuild` 报错。现已通过配置 `ESBUILD_BINARY_PATH` 指向 `app.asar.unpacked` 彻底解决。
- **修复动态路由表过期问题**：前端 `fetch` 拦截器改为每次请求实时向主进程拉取最新路由表，彻底解决壳页面加载早于插件注册导致的网络请求匹配失败。
- **修复开发版 `pnpm 不可用`**：修正了路径推算少一级的 Bug，现在卸载/安装插件不会在开发环境下报错。
- **修复跨域预检失败**：为本地 HTTP 服务器补充了 `OPTIONS` 请求处理和全局 CORS 头。

## 🧹 优化与清理
- **移除冗余的「记忆」功能**：彻底清理了相关的 UI、主进程 IPC、底层工具以及提示词注入，保持内核纯净。
- **精简插件安装入口**：移除了原生手输 npm 包名的「DSH 插件」区块，统一交由插件市场（`dshmarket`）接管，交互更清晰。
