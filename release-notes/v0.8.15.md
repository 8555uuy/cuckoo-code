# v0.8.15 — 稳健性增强（换行符编辑 + 危险命令 + 上下文续接）

本次亮点速览：

1. **编辑文件不再破坏混合换行符** —— 编辑混合换行符（CRLF/LF 并存）文件时，只改写命中的区域，未编辑区域的行尾逐字节保留，不再全文规整、消除 diff 噪音。
2. **危险命令检测增强** —— 修复前缀修饰词（`sudo`/`env`/`nohup`）、通配符根目录（`rm -rf /*`）、长选项（`--recursive --force`）等绕过检测。
3. **窗口组转移对话更完整** —— 复用压缩的 IDB 重写逻辑，转移时拿到完整对话历史（不再缺消息）。
4. **上下文耗尽自动续接更智能** —— 会话上下文耗尽时，新会话会自动带上中断前的工具执行结果，AI 能接着干活（不再丢失）。

> 特别感谢本版的外部贡献者：**@8555uuy**（PR #38 危险命令检测增强、PR #39 换行符编辑修复）。

## 📝 编辑文件不再破坏混合换行符

此前编辑**混合换行符**文件（CRLF + LF 并存）时，会把全文统一成主导格式，导致大量未编辑区域的行尾被改、diff 噪音巨大。

本次改为**局部替换**：

- 建立「LF 归一文本 → 原文索引」映射，只改写命中区间
- **未编辑区域逐字节保留**（行尾原样不动）
- 新文本行尾跟随匹配处风格（匹配 CRLF → CRLF，纯 LF → LF）

（**@8555uuy**，PR #39）

## 🛡️ 危险命令检测增强

修复 PR #30 遗留的 4 类绕过：

| 命令 | 原结果 |
|---|---|
| `sudo rm -rf /`（前缀修饰） | 放过 |
| `rm -rf /*`（通配符根目录） | 放过 |
| `rm -rf --no-preserve-root /`（长选项） | 放过 |
| `rm --recursive --force /`（长选项） | 放过 |

新增 `stripWrappers` 剥除前导修饰词（`sudo`/`doas`/`env`/`nohup`/`command` 等，支持 `-u user` 选项、`FOO=1` 环境变量），并改进 `rm` 模式支持任意短/长选项组合与通配符根目录。

（**@8555uuy**，PR #38）

---

## 🔄 窗口组转移对话更完整

窗口组的「转移对话」此前直接读 IndexedDB 取历史——但 DeepSeek 的 IDB **同会话内不更新**（回复后不写，刷新才补齐），导致转移拿到旧/不全的消息。

本次**复用压缩的「清 IDB → 刷新 → 等重写 → 再读」**链路：

- 源窗口清 IDB + 刷新，等 DeepSeek 重建完整历史后再全量分享
- 目标窗口加载完整对话，用原项目目录初始化

---

## 💬 上下文耗尽自动续接更智能

ChatGPT 会话上下文耗尽时，此前自动开新会话只发系统提示词——**丢掉了中断前刚执行完的工具结果**，AI 不知道干了啥。

本次：耗尽瞬间**捞回工具结果**（优先待发的，否则用最近已发出的），作为续接说明追加到新会话提示词末尾：

```
【续接说明】上一会话因上下文耗尽中断。中断前最后一个工具调用的执行结果如下，
请据此继续工作（不要重复执行同一工具；如需更多上下文，请用工具读取项目文件）：
<工具结果原文>
```
