# v0.8.8 Release Notes

> 发布日期：2026-10-04

本次更新带来**插件市场**、**纯净对话模式增强**、**工作区会话血缘**等多项重要功能，并感谢 @27584 贡献的 PR #23。

---

## ✨ 新增功能

### 插件市场（Plugin Market）
- 侧栏新增「插件」页，以 GitHub topic:cuckoo-plugin 为搜索源自动发现插件仓库
- 一键安装 / 卸载 / 启停
- 插件是**分发容器**：可打包技能 / 代理 / 规则 / MCP 配置 / 自定义平台，复用既有五套扫描机制，不引入新运行时
- 可执行内容（providers/*.js）默认不落盘，需显式授权
- 安装走 codeload.github.com（不消耗 GitHub API 配额）；解压拒绝绝对路径 / 符号链接，防路径穿越

### 纯净对话模式（Harness）增强（PR #23）
- 多会话隔离：历史、Goal 目标、Plan 计划按会话 ID 隔离，切换不再串会话
- 侧栏「对话」分页：实时读取网页端会话列表，支持切换 / 新建 / 刷新
- Markdown 渲染增强：表格、多级标题、列表、引用、删除线
- **KaTeX 数学公式**（离线内置）：支持行内 / 块级 LaTeX，无外部网络依赖
- Goal / Plan 自动驱动；计划复用官方 todoWrite 规范化结果

### 工作区
- 新增**会话血缘**：对话可展开查看「子代理」与「压缩历史」两个分组
- 压缩后子代理从血缘链收集，展开仍可见
- 侧栏「项目文件」页：VSCode 风文件树，类型图标 / 配色、文件名搜索、悬停 @ 一键引用路径
- 侧边栏支持**拖拽调宽**（最小 320px，记忆宽度）

### 其他
- 地址栏「新建对话」按钮：原主页图标改为加号（+），点击新建对话并清理纯净模式视图
- AI 自动命名对话：nameConversation 工具，工作区列表实时刷新

---

## 🔧 优化
- **子代理复用父窗口 profileId**：会话 / token 计入父窗口，不再产生 session-dir-map-subagent-*.json 垃圾文件；防递归改用 ctx.isSubagent 标志位
- 工具结果追加到输入框，不再覆盖用户已输入内容
- 侧栏「最近使用」按钮点击不再重排

---

## 🐛 修复
- **纯净模式：对话流空白 + 状态永久卡在运行中**：删除上报门控，新增权威生成状态心跳 ai-state；改用权威终态信号 task-idle 收尾，不再依赖超时猜测
- **纯净模式：网页答完仍显示「运行中」**：tool-end 不再无条件置忙，兜底有界（框架窗口 120s / 窗口外 60s）
- **纯净模式：页面导航后上报静默失效**：彻底移除门控，系统提示词改由主进程直推
- **纯净模式下框架自动消息无状态反馈**：系统提示词、工具结果回传等投递会在状态栏显示来源，并阻止用户插话
- **DeepSeek 限流文案检测**：响应体含「频率过快」等按操作频繁处理；429 重试默认值调整为 120s / 40 次
- **静默兜底不再「猜结束」**：避免模型首个 token 延迟较久时误显示「就绪」
- 停止时先向 bridge 下发停止信号，修复停止后仍自动发送的问题
- 工具回合 / 纯思考回合正确收尾思考气泡，修复「思考中…」悬留
